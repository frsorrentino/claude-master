- **0.4.18 — 2026-09-23: an approval queue for the user's oks, a durable inbox between sessions, and the day's «between sessions».**

A session that reaches a step needing the user's ok (push, release, public repo, deploy, payment, install) asks for it and ends its turn; the outcome reaches it on its own. - **0.4.11 — 2026-09-16: the model and the context of a session are read where Claude Code actually writes them.**
  - Contract 1.11.1 (reported by the watch session at 08:13, minutes after 0.4.10 went out: on the wrist `model.label` and `context` were null on every live session). The entry that carries the model's full id and its name is written by Claude Code at the START of a conversation, so in any session of some length it sits far outside the last 512 KB, which is all the relay read: measured on a real transcript, one single entry at 221 KB of 4.5 MB.
